# global_tea_polygons
In this repository I host tea polygons dataset which can be used for mapping tea plantations globally. It follows from our recent paper published in ERL (https://doi.org/10.1088/1748-9326/ae9b28) and part of the data already in Zenodo (https://doi.org/10.5281/zenodo.21071459). It will be continuously updated over the years.
