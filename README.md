# global_tea_polygons
Here, I host a global tea polygons dataset that can be used for mapping tea plantations globally. It follows from our recent paper published in ERL (https://doi.org/10.1088/1748-9326/ae9b28) and part of the data already in Zenodo (https://doi.org/10.5281/zenodo.21071459). It will be continuously updated over the years. Please cite original paper or zenodo dataset when using this dataset.
label = 1 ==> Tea plantation for the period 2003 - 2025 (Data digitization period)
The labels were generated by manual annotation in QGIS using Google Satellite basemap.
